## 🚀 Featured Project

### 📦 Synchronous FIFO Design & Verification

A **synchronous FIFO** designed at the RTL level and verified using a **SystemVerilog-based testbench**.

#### 🔹 Design

* Implemented FIFO read and write operations
* Designed control logic for FIFO operation
* Generated **Full** and **Empty** status flags
* Handled normal and boundary operating conditions
* Verified synchronous operation with a common clock

#### 🔹 Verification

* Developed a SystemVerilog testbench
* Verified normal write and read operations
* Tested FIFO **Full** condition
* Tested FIFO **Empty** condition
* Verified boundary conditions
* Analyzed simulation waveforms for functional correctness
